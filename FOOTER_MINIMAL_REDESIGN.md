## Design Specifications

### Layout
- **Structure:** Single horizontal flex row with clean spacing
- **Alignment:** Items aligned center vertically, copyright pushed to right with `ml-auto`
- **Padding:** Reduced to `py-5` for minimal footprint
- **Border:** Thin single border-top (border-purple-900/30)
- **Background:** Pure black (#000000) for maximum contrast

### Typography
- **Logo:** 
  - Font: Unbounded
  - Size: text-xl (20px)
  - ShinyText animation (speed: 4s)
  - Gradient: orange-500 to purple-500

- **Email Input:**
  - Font: Unbounded
  - Size: text-xs (12px)
  - Width: 48 (192px)
  - Compact padding: px-3 py-1.5

- **Subscribe Button:**
  - Size: text-xs
  - GlareHover effect with purple glare
  - Just ghost emoji (👻) for minimal design

- **Contact Icons:**
  - Size: text-base (16px)
  - Gray-400 default, purple-400 on hover
  - Hover glow effect

- **Copyright:**
  - Font: Orbitron
  - Size: text-xs (12px)
  - Color: gray-500

- **Creator Credit:**
  - Font: Unbounded
  - Size: 9px (extra small)
  - Color: gray-700 with 40% opacity
  - Letter spacing: 0.5px
  - Nearly invisible but still readable

### Interactive Elements

**Contact Icons:**
- Hover scale: 1.15x
- Purple glow on hover (drop-shadow)
- Radial gradient background appears on hover
- Smooth transitions

**Email Input:**
- Focus state with purple border
- Subtle border glow

**Subscribe Button:**
- GlareHover animation
- Scale on hover (1.05x)
- Purple/orange gradient background
