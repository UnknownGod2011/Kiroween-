## 🔧 To Use This Repository

### Clone:
```bash
git clone https://github.com/UnknownGod2011/Kiroween-.git
cd Kiroween-
```

### Install Frontend:
```bash
cd project
npm install
npm run dev
```

### Install Backend:
```bash
cd backend
npm install
node index.sd.js
```

### Install Python VITON:
```bash
cd python-viton
pip install -r requirements.txt
python app.py
```

### Install DeepFashion (Optional):
```bash
cd deepfashion-backend
pip install -r requirements.txt
# Download checkpoints (see DEEPFASHION_SETUP.md)
python main.py
```
