## 🎨 CSS/Styling Details

### Gradients
```css
/* Background */
from-gray-900 via-purple-950 to-black

/* Cards */
from-gray-900 to-purple-950

/* Buttons */
from-orange-600 to-purple-700

/* Footer sections */
from-purple-950 to-orange-950
```

### Borders
```css
border-purple-700/50  /* Semi-transparent purple */
border-orange-700/50  /* Semi-transparent orange */
```

### Text Colors
```css
text-orange-400  /* Primary headings */
text-orange-500  /* Emphasis */
text-purple-300  /* Body text */
text-purple-400  /* Secondary text */
```

### Shadows
```css
shadow-2xl shadow-purple-900/50  /* Purple glow */
shadow-lg shadow-orange-900/50   /* Orange glow */
```
